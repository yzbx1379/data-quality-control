# 数据集交付模板规范

三类数据集（代码问答 / 安全技术博客 / 漏洞修复 commit）的完整交付物料清单与统计口径模板。

> ## ⚠️ 质检报告结论仅供参考
>
> **质检报告结论仅供参考，须人工复检或大模型逐条确认后方可作为验收结论。**

**通用约定**：交付包一次性提供以下全部物料，**缺失任意文件不予验收**。

**归档约定**：交付的数据需要**按照来源归档**，一个来源的数据打一个 `.zip` 压缩包，包内为一份完整交付四件套（`<来源>_data.jsonl`、`metadata.csv`、`README.md`、质检报告）。压缩包命名规范：`<数据集>_<来源>_<数量>.zip`，示例：`代码问答数据_CodeChef_10w.zip`。

---

## 1. 代码问答

### 完整交付物料清单

| #   | 物料                        | 要求                                                                                                              |
| --- | --------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| 1   | 核心数据集                  | 分批次 JSONL 文本数据文件                                                                                         |
| 2   | 元数据统计表 `metadata.csv` | 统计维度见下表                                                                                                    |
| 3   | 数据质检报告                | 抽样代码功能校验、问答真实性校验、重复率校验、脱敏校验、低质样本过滤记录、问题整改明细                            |
| 4   | `README.md` 文档            | 数据集采集流程、网页爬取规则、清洗去重流程、匿名化规范、JSON 字段释义、问答分类说明、版权合规说明、数据集使用限制 |

### metadata.csv 统计维度

| 统计维度                   | 说明                                      |
| -------------------------- | ----------------------------------------- |
| 总样本条数                 | 全数据集记录总数                          |
| 单轮 / 多轮问答样本数量    | 分别统计并给出占比（多轮占比硬指标 ≥10%） |
| 全数据集总 tokens          | 分词后 token 总量                         |
| 各编程语言样本数量及占比   | 单一语言占比硬指标 ≤30%                   |
| 各数据源渠道样本分布统计   | `source` 字段维度                         |
| 各技术领域问答样本数量分布 | `domain` 字段维度                         |
| 脱敏覆盖统计               | 隐私脱敏处理覆盖情况                      |
| 全局重复率检测结果         | 硬指标 <0.5%                              |

## 与本仓库质检脚本的对应关系

| 交付物料             | 生成 / 校验脚本                                                                    |
| -------------------- | ---------------------------------------------------------------------------------- |
